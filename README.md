<h1>✨ Clean old docx files in a folder ✨</h1>
A script/program to clean/remove old docx files in a folder.<br>
THANKS TO:
A had a from Google Gemini in the making of this project.

<h2>🛠️ Functions</h2>
    ✅ Startup dialog with welcome message
    ✅ List of files that the script wants to remove
    ✅ Yes/No question
    ✅ You must press enter to exit the script

<h2>🚀 Installation and ⚙️ config:</h2>
Follow these steps to install the application.

1. Get the repo from GitHub to a folder in your server/system.
2. Edit the following rows in the file "clean-old-docx.ps1"
   Row 1: Change to your user account on the computer.
   Row 10: Change to your wanted folder
